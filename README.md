Summary
In this assignment, my goal was to build a multi-section webpage from scratch using modern CSS layout techniques instead of old methods like floats. 
I practiced using Flexbox for one-dimensional layouts (like aligning links in a row and structuring elements inside cards). For the larger, two-dimensional structures, I used CSS Grid, which made it easy to build a complex layout with grid-template-areas and create a perfectly aligned 3x3 photo gallery. Finally, I successfully integrated both Flexbox and Grid in the last task, showing how they work together to create a clean, responsive, and well-aligned design.
